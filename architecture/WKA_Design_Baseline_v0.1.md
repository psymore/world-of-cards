# WKA Design Baseline v0.1

This baseline consolidates the agreed architecture.


## Normative Principles
- Single Responsibility
- Single Source of Truth
- Specification-first
- Refinement over Expansion

## Layer Model
Overview -> Foundation -> Conceptual -> Representation -> Evolution -> Specifications -> Reference Implementations

## Core Definitions
Purpose, Quality Attributes, Engineering Principles, Knowledge Domain, Governance,
Knowledge Artifact, Documentation Structure, Documentation Map, Naming,
Templates, Knowledge Lifecycle, Specification, Reference Implementation,
ADR, Mechanisms.

## Relationship Rules
Specifications define.
ADRs justify.
Governance defines rules.
Mechanisms support governance.
Implementations realize specifications.

## Lifecycle
Proposed -> Accepted -> Active -> Deprecated -> Archived

## Authoring Order
ADR-000 -> Overview -> Foundation -> Conceptual -> Representation -> Evolution -> Specifications -> Reference Implementations

## Reading Order
Overview -> Foundation -> Conceptual -> Representation -> Evolution -> Specifications -> Reference Implementations

## Cross References

Other sections reference them rather than redefining them.
